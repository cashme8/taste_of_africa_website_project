# Taste of Africa

A multi-page website celebrating the rich and diverse cuisines of Africa. Visitors can browse traditional recipes, explore food by region, and learn about the dishes and cultures behind them.

## Pages

| Page | File |
| --- | --- |
| Home | `index.html` |
| Recipes | `recipes.html` |
| Regions | `regions.html` |
| About | `about.html` |
| Contact | `contact.html` |

### Recipe pages (`recipes/`)
- Jollof Rice — `recipes/jollof-rice.html`
- Tagine — `recipes/tagine.html`
- Injera — `recipes/injera.html`
- Bunny Chow — `recipes/bunny-chow.html`
- Isombe — `recipes/isombe.html`

### Region pages (`regions/`)
- West Africa — `regions/west-africa.html`
- North Africa — `regions/north-africa.html`
- East Africa — `regions/east-africa.html`

## Technologies Used

- HTML5
- CSS3 (custom properties, Flexbox/Grid)
- Vanilla JavaScript (no frameworks)
- Google Fonts (Abril Fatface, Nunito)

## Project Structure

```
├── index.html, recipes.html, regions.html, about.html, contact.html
├── recipes/      # Individual recipe pages
├── regions/      # Regional cuisine pages
├── css/styles.css
├── js/script.js
└── images/
```
